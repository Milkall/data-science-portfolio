# Does the Flight + Hotel Package Increase Bookings?

A causal analysis of Expedia search data: separating the effect of the package from differences between the customers who choose it.

## Files

- **[`expedia_causal_inference_report.md`](expedia_causal_inference_report.md)** – Full report: question, method, results and next steps. **Start here.**
- **[`expedia_causal_inference.ipynb`](expedia_causal_inference.ipynb)** – Python notebook with all the code and outputs.
- **[`figures/`](figures/)** – Charts used in the report.

## Data

[Kaggle – Expedia Hotel Recommendations](https://www.kaggle.com/competitions/expedia-hotel-recommendations/data) (`train.csv`, `destinations.csv`). Not included because the files are too large.
